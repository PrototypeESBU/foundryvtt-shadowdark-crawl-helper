# Shadowdark RPG Crawl Helper

Crawl Helper streamlines dungeon crawling and combat transitions in your Shadowdark RPG games on Foundry VTT. Designed to support both structured exploration and fast-paced combat, this module enhances your game flow with intuitive tracking and automation.

## Features

### GM tools 
UI to control crawl tracking features and trigger automations.
![crawl1](https://github.com/user-attachments/assets/ca5e76f3-27c4-43ec-b71f-4919491994e5)

### Visual Crawl & Combat Tracker
Adds an new visual crawl / combat tracker but also works with Foundry's default tracker and other combat modules.
![crawl2](https://github.com/user-attachments/assets/bf96dee5-c1fb-47bc-ac4a-9485f4a8fca5)

### Crawl & Combat Tracking
Display current crawl round and transition smoothly into and out of combat.
![crawl 3](https://github.com/user-attachments/assets/61d1be47-286a-47d7-8c1b-2f9d7ac2d141)

### Automated Encounter Rolls
For each scene, GMs can set the danager level and add a rolltable that gets rolled automatically when an encounter is triggered.

### Other Features
- **Adds GM Turn Placeholder** – Ensures the GM has a dedicated turn in the round order.
- **Player Turn Notifications** – Keeps players engaged with clear turn prompts.
- **Time Passes** - Quickly advance time forward and clear round based effects.
- **Death Timer** - Track dying character's remaining turns and prompt for rolls.
- **Lights Out Integration** - Works with the lights out UI module.
- **NPC Masking** - Hide individual monster names from players.
