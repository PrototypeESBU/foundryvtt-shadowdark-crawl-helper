# v1.0.0

First release

## Changes
- Crawl Helper now only works on Foundry v13.
- UI elements have been redesigned.
- Many code quality and technical fixes.
- The hidden toggle for combatant now works similar to the default combat tracker, but will now also hide the combatant's token.
- [#28] Death Timer automation added. Triggers when characters go to 0 HP.
- [#29] Carousel buttons have been repositioned. Player buttons now appear in the position of the GM buttons.

## Experimental Features
- The masked toggle will hide monster names from players. Some chat cards may still display the monster's name.
